# CBG-SiN 综述论文与30天学习路线映射

> 本文档将 `review_cbg_sin_v3.tex`（氮化硅波导啁啾布拉格光栅综述）的每个章节映射到30天学习路线的对应阶段，形成"**先学理论→再看综述对应章节→再精读原始论文**"的递进阅读路径。

## 使用方式

1. 按天完成理论学习后，打开综述 PDF 阅读"对应综述节"
2. 综述中提到的关键论文，按"原始论文"列精读
3. "重合度"标注综述与理论学习的交叉程度：★ = 综述提供背景；★★★ = 综述是该阶段的核心阅读材料

### 综述 §2 导读要点

综述 §2 是理论基石，与阶段一高度重合：
- **§2.1** 从 CMT 方程出发推导均匀光栅解析解——这正是第 2–3 天的核心。注意综述使用的时间因子约定（$e^{-i\omega t}$）和符号体系与学习包一致。

### 垂直光栅耦合器的特殊说明

综述论文以 **啁啾布拉格反射光栅**（波导内前向—后向耦合）为主线，而垂直光栅耦合器涉及 **波导模式到自由空间辐射模式** 的耦合，这是物理机制上的跃迁。建议的阅读顺序：

1. **先读** Tamir–Peng 1977（经典理论）→ 理解周期性波导中导模→辐射模耦合的基本框架
2. **再读** Taillaert 2006 + Van Laere 2007（SOI 光栅耦合器的实验和设计）→ 理解实际器件的设计逻辑
3. **然后读** Zhao–Fan 2020（解析切趾的现代处理）→ 理解从目标高斯场反推 $\alpha(z)$ 的数学
4. **进阶** Benedikovic 2015（亚波长工程）+ Michaels–Yablonovitch 2018（逆向设计）→ 理解突破效率极限的前沿方法
5. **平台特定** Xue 2025（LNOI）或 Zou 2015（SiN）→ 理解材料平台对垂直光栅设计的具体约束

## 综述论文的"分级阅读"指南

根据学习进度，综述可以分三个层次阅读：

### 第一遍：概览级（第 1 天前或第 1 天）

- 读 §1（引言）和 §7（总结与展望）
- 目标：建立领域全景图，知道"有哪些问题"和"谁在做"
- 时间：30–45 分钟

### 第二遍：理论级（第 5, 10, 17, 22, 28 天各阶段结束时）

- 读 §2（基本原理与设计方法）
- 目标：用自己的理论推导验证综述中的每一个公式
- 时间：每次 20–30 分钟

### 第三遍：论文级（第 30 天综合时）

- 全文精读，逐条对照参考文献
- 目标：能将综述中的每一句话定位到对应的原始论文和教材章节
- 时间：2–3 小时
